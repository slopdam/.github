# slopdam/.github

Special repository for the `slopdam` GitHub organization. It must be public.

- `profile/README.md` is shown on https://github.com/slopdam.
- Community files placed at the root of this repository (`CODE_OF_CONDUCT.md`, `SECURITY.md`, `CONTRIBUTING.md`) become the defaults for every public repository in the organization that lacks its own. The `slopdam` repository has its own, so none are kept here.
