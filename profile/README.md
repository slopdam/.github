## slopdam

**AI slop이 로그와 화면으로 흘러넘치기 전에 막는 댐.** 슬롭은 막고, 문장은 담백하게.

AI가 만든 코드와 글에는 `ㅡ` `—` 대시, ✅🚀 이모지, `=====` 구분선, `**굵게**` 같은 흔적이 남습니다. slopdam은 이 흔적을 출력 단계(로거 포맷터)와 커밋 단계(린터)에서 걸러냅니다.

```
입력  : ✅ **저장 완료** ㅡ 2024–2025년 데이터 3건 처리했습니다! 🎉
reader: 저장 완료: 2024~2025년 데이터 3건 처리했습니다.
dev   : [OK] 저장 완료 - 2024-2025년 데이터 3건 처리했습니다!
```

| 저장소 | 설명 |
|---|---|
| [slopdam](https://github.com/slopdam/slopdam) | 오픈소스 코어 (MIT). Python 로거 포맷터, 린터, CLI |

설치: `pip install slopdam`
